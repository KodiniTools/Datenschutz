3. Datenverarbeitung: Browser (Lokal) vs. Server

Auf unserer Plattform bieten wir zwei technisch unterschiedliche Verarbeitungsarten an, die bei jedem Tool transparent ausgewiesen sind:

Client-seitige Tools (Lokale Verarbeitung)
Diese Werkzeuge nutzen moderne Web-Technologien und verarbeiten Ihre Dateien (z. B. Bilder, Code oder Audio) ausschließlich lokal im Arbeitsspeicher Ihres Endgeräts. Ihre Dateien werden zu keinem Zeitpunkt an unsere Server übertragen. Wir haben weder Einsicht noch Zugriff auf diese Inhalte.

Server-gestützte Tools (Temporäre Verarbeitung)
Bestimmte rechenintensive Operationen erfordern serverseitige Rechenleistung. Bei diesen Tools werden die von Ihnen ausgewählten Dateien über eine TLS-/SSL-verschlüsselte Verbindung an unseren Webserver übertragen, dort automatisiert verarbeitet und für Sie zum Download bereitgestellt.

  • Verwendungszweck: Die Dateien dienen einzig der Ausführung der angeforderten Operation.
  • Keine Inhaltsanalyse / Kein KI-Training: Ihre Dateien werden zu keinem Zeitpunkt manuell gesichtet, ausgewertet oder für das Training von Machine-Learning-/KI-Modellen herangezogen.
  • Automatische Löschung: Hochgeladene Quelldateien sowie das Verarbeitungsergebnis werden nach maximal 12 Stunden unwiderruflich und automatisiert vom Server gelöscht.

3. Data Processing: Browser (Local) vs. Server

Our platform offers two technically distinct types of processing, which are transparently indicated for each tool:

Client-Side Tools (Local Processing)
These tools use modern web technologies and process your files (e.g. images, code or audio) exclusively locally in the memory of your device. Your files are never transmitted to our servers. We have neither insight into nor access to this content.

Server-Based Tools (Temporary Processing)
Certain computationally intensive operations require server-side computing power. With these tools, the files you select are transmitted to our web server over a TLS/SSL-encrypted connection, processed there automatically and made available to you for download.

  • Purpose of use: The files are used solely to perform the requested operation.
  • No content analysis / no AI training: Your files are never manually reviewed, evaluated or used to train machine learning/AI models.
  • Automatic deletion: Uploaded source files and the processing result are irrevocably and automatically deleted from the server after a maximum of 12 hours.

4. Provision of the Website and Server Log Data

When you access our website, the server briefly processes, for technical reasons, data that your browser transmits automatically (including IP address, date and time of access, volume of data transferred, browser type and operating system).
